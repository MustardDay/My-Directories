## **80x15px Antipixel/Brilliant Button**

[ACA 80x15 Brilliant Button Maker: Make your antipixel button with one click\!](http://www.acasystems.com/en/button-maker/) \- “Pick some colors, enter some text, and you'll get a button you can download for your site.”

[web-badges-world](https://web.badges.world/) \- “I made this website to *save **web badges*** and bring them back into popularity by reminding everyone how cool they were with this huge collection of nearly 4,000 examples\!”

[trovami.altervista.org (button maker)](https://trovami.altervista.org/en/webmasters/makebutton) \- ![80x15 Brilliant Button Maker][image1] “is an easy web 2.0 style **button generator**. Use this tool to create your own **80x15 Brilliant Buttons** (also known as "**Antipixel Buttons**" or "**Badges**") in few seconds\! Pick some colors, enter some text, and you get a button you can put in your site.” 

[Buttonbrowser.com (button maker) (Wayback Machine Archive)](https://web.archive.org/web/20120317204302/http://www.buttonbrowser.com/main/index.php?page=buttonmaker) \- “With this buttonmaker, you can create your own antipixel buttons.In the [historylist](https://web.archive.org/web/20120317204302/http://www.buttonbrowser.com/main/index.php?page=buttonmaker_recent) you can see recently created buttons. They can be modified again, just click on it.”

## **88x31px Button**

[88x31 Web Button Maker](https://hekate2.github.io/buttonmaker/) \- “1. Gif saving is not an option yet, sorry :-(. 2\. To remove an element, double click on it. 3\. All elements on the stage are draggable\! 4\. If you have any suggestions, and especially if you have any ideas about how to capture a div as a gif, let me know [here](https://github.com/hekate2/buttonmaker/issues)\!”

[88x31 Button Maker \- Retro Edition](https://pixelwolf.net/PWapps/88x31/) \- 88x31px button generator with presets and animations

[88x31px Button Generator by datakra.sh](https://88x31.datakra.sh/) \- “Here, you can whip up some rad 88x31 web buttons in glorious web 1.0 style. Enjoy, I guess?” (If you can’t see the background color, change to “No Template”)

[88x31 Button Maker](https://codepen.io/sadness97/full/YPXMmve) \- Sadness97 88x31px button maker

[ritual.sh | 88x31 Button Creator](https://ritual.sh/resources/button-generator/) \- “Welcome to my 88x31 button creator, this is a pretty rough and ready implementation so it could be buggy, please let me know if you find any issues. This supports gif despite the basic `canvas` tag limitation courtesy of [gif.js](https://github.com/jnordberg/gif.js) \- none of this would be possible without that project.”
